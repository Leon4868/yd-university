# YD University 需求基线 v0.1

## 已冻结规则

| 规则 | v0.1 决策 |
| --- | --- |
| 网络 | Ethereum Sepolia，Chain ID `11155111` |
| YD 供应量 | 固定 `100,000 YD`，部署时一次性铸造 |
| 课程价格 | 默认 `4 YD`，课程管理员可修改 |
| 收益分配 | 教师 70%、商家 20%、平台 10% |
| 证书 | ERC721 兼容、不可转让、可由管理员说明原因后撤销 |
| 完成条件 | 所有课程小节完成，聚合进度达到 100% |
| 自动发证 | Chainlink CRE 把后端完成记录传给接收器后触发 mint |

## 链上数据

- YD 余额、授权额度和转账。
- `courseId`、教师钱包、商家钱包、价格、分账比例、课程状态、metadata URI。
- 课程购买关系、实际支付价格、三方可提现收益。
- 证书 token、课程 ID、学生钱包和 metadata URI。
- 已消费的完成报告 ID，防止 CRE 重放。

## 链下数据

- Privy 用户 ID、用户名、头像、主钱包。
- 课程正文、封面、视频、章节、评论和审核资料。
- 每节课的完成状态和聚合进度。
- 链上事件索引副本和同步游标。

## MVP 验收路径

```text
登录
→ 浏览课程
→ 获取 YD
→ approve 课程价格
→ buy(courseId, maxPrice)
→ 后端确认 CoursePurchased 事件
→ 学习全部章节
→ 进度达到 100%
→ CRE 提交唯一完成报告
→ 铸造不可转让证书
```

## 当前不做

- 主网部署、公开售币或真实资产承诺。
- 链上保存视频、评论或高频学习进度。
- DAO、可升级代理、交易税、黑名单和无限增发。
- YD/WETH 第二个池；第一阶段只规划 YD/USDC。
